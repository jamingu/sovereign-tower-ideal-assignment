# Notes de développement

> **Spoilers.** Ces notes décrivent les mécaniques internes du jeu : formule de
> score, issues de quête, structure du scénario. À ne pas lire avant d'avoir
> joué.

Elles sont en français, écrites au fil du développement, et servent surtout à
retrouver *pourquoi* une décision a été prise.
